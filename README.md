# Portfolio

Static personal portfolio site built with plain HTML, CSS, and JavaScript.

## Deploy on GitHub Pages (Recommended)

1. Push this repository to GitHub (use `main` as the default branch).
2. Open the repository on GitHub and go to **Settings → Pages**.
3. In **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Click **Save** and wait for deployment.
5. Open the published URL (typically `https://<username>.github.io/Portfolio/`).

## Other deployment options

- **Netlify:** Import this repo or drag-and-drop the project folder.
- **Vercel:** Import this repo, choose framework preset **Other**, output at root.
- **Cloudflare Pages:** Connect this repo and deploy as a static site.
